# mini-whacJS

Lern-Repository für JavaScript mit kleinen Browser-Projekten und Übungen.

## Projekte

| Ordner | Inhalt |
| --- | --- |
| `WhacAMoleGame/` | Whac-a-Mole im Browser (Vanilla JS) |
| `BirthdayCountdown/` | Countdown bis zum nächsten Geburtstag |
| `CodeMe/Basics/` | PigGame, GuessNumber, ModalWindow, Countdown |
| `CodeMe/` (Rest) | Übungen zu Algorithmen, Datenstrukturen, OOP |
| `React/` | erste React-Experimente |

## Starten

Die Projekte brauchen keinen Build. `index.html` im jeweiligen Ordner im Browser öffnen.

## Hinweis

Dateien mit API-Zugangsdaten gehören nicht ins Repo (siehe `.gitignore`).
